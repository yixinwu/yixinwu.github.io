1 Cadence 新闻稿分析

📰 Cadence 拓展 ChipStack AI Super Agent：新增 RTL 生成与早期 PPA 优化智能体

发布日期：2026年9月22日 · 来源：Cadence Newsroom

Cadence 宣布为其 ChipStack™ AI Super Agent 新增一款 RTL 生成智能体（RTL Generation Agent），将能力从自主验证与调试扩展至高质量 RTL 创建与优化，实现前端数字设计与验证的全面自动化。

该智能体可通过自然语言提示驱动，覆盖：以 PPA（功耗、性能、面积）为目标的规格→RTL 生成、RTL 分析与优化，以及对现有 RTL 的设计更新（RTL Upgrade Flow）。

分析要点

1. 从工具到虚拟工程师的范式转变：Cadence 正在将 AI 从"辅助工具"升级为"自主智能体工作流"，模拟虚拟设计工程师的角色。

2. PPA 优化是核心差异化优势：24% 面积缩减 + 18% 功耗降低 + 100% 功能准确，远超通用大模型代码生成能力。

3. 端到端覆盖：从规格→RTL 生成→优化→验证→实现→签核，构建覆盖芯片设计全流程的 AI 智能体平台。

上市时间：扩展后的 ChipStack 和 InnoStack AI Super Agent 功能预计于 2026 年第四季度向部分早期体验客户开放。

NVIDIA — 最深度合作伙伴

NVIDIA 是 ChipStack 最核心的 AI 合作伙伴，合作涉及多个层面：

• NVIDIA Nemotron 模型：Level-5 自主虚拟工程师的驱动模型

• NVIDIA OpenShell 运行时：沙箱化安全运行环境，保护敏感 IP

• NVIDIA 加速计算基础设施：为长时间运行的多智能体工作流提供算力

核心差异化：Mental Model 技术

ChipStack 的真正技术壁垒不在于用了哪个 LLM，而在于其独创的 Mental Model 技术：

• 结构化知识表示：显式捕获设计意图、层次结构和关系

• 持久真相源：作为所有智能体共享的知识基础，弥合人类意图与机器推理

• 解决 LLM 短板：Cadence 研究表明，单纯依赖 LLM 无法可靠生成高质量 RTL

• LLM 提供推理，Mental Model + EDA 引擎提供准确性，两者结合才是核心竞争力

4 核心技术深度解析

1. Mental Model（心智模型）— 核心技术发明

本质：一种结构化知识表示方法，从 RTL 代码或规格说明中推断设计意图，显式捕获设计意图、层次结构和模块间关系。

作用：作为所有 AI 智能体共享的"持久真相源"，弥合人类设计意图与 LLM 机器推理之间的鸿沟。

价值：Cadence 研究表明，单纯依赖 LLM 无法可靠地生成高质量 RTL 和验证测试平台。Mental Model 将多模态规格说明、设计源码和历史上下文转化为统一知识库，使 LLM 生成内容的质量和准确性大幅提升。

6 总结

ChipStack 是一家典型的"学术创业"公司——两位创始人均为顶尖高校博士，在芯片设计和 AI 领域有深厚积累。公司从 2023 年成立到 2025 年被收购仅用约 2 年时间，核心原因在于：

1. 技术方向精准：抓住了 LLM + EDA 融合的窗口期，用 Mental Model 解决了 LLM 不懂芯片设计的核心痛点。

2. 团队背景过硬：CEO 有 Arm/NVIDIA/Meta 经历，CTO 有 Google TPU/Qualcomm 经历，17+ 年芯片验证经验。

3. 产品快速落地：成立后即推出产品，验证周期缩短 70%，赢得头部客户信任。

4. 与 Cadence 的生态协同：双方在收购前已有多年技术集成合作，收购是水到渠成。

被 Cadence 收购后，ChipStack 的技术从"验证自动化"扩展到"RTL 生成 + PPA 优化 + 全自主虚拟工程师"，成为 Cadence AI 驱动芯片设计战略的核心引擎。底层 LLM 采用多模型灵活架构（NVIDIA Nemotron / Google Gemini / OpenAI GPT / 开源模型），但真正的技术护城河是 Mental Model 结构化知识表示 + Cadence 签核级 EDA 引擎。
